# 汉化说明

适用补丁：**v2.1.0**。验证环境：**Windows，Antigravity 2.26.0**。当前词库：**1,236 条**。

## 1. 安装准备

需要先安装 Antigravity 和 Node.js 18 或更新版本。终端中执行：

```powershell
node --version
```

出现版本号后即可使用补丁。安装补丁无需 npm 依赖，也无需修改代理、账号或模型配置。

下载 Release 中的 `Antigravity-Chinese-Localization-v2.1.0.zip` 并解压。不要在压缩包预览窗口内直接运行脚本，也不要单独复制一个 BAT 文件：词库和 JavaScript 文件需要位于同一个文件夹。

补丁面向包含 `resources/app.asar` 的桌面应用结构，归档内要求 `package.json` 的 `name` 为 `antigravity`、入口为 `dist/main.js`，并具有兼容的 `dist/preload.js`。不同产品、同名程序或大幅改版后的应用可能不兼容。

## 2. 安装与检查

1. 保存正在编辑的内容，退出 Antigravity，并从托盘退出后台进程。
2. 双击 `install_chinese.bat`。
3. 等待出现“汉化已安装，启动 Antigravity 即可生效”。
4. 重新启动 Antigravity，检查导航、设置等界面。
5. 如需确认状态，双击 `check_chinese.bat`。

默认会查找当前用户的 `%LOCALAPPDATA%\Programs\antigravity\resources` 及 `%ProgramFiles%\Antigravity\resources`。脚本提示应用仍在运行时，请退出应用后重试。

安装目录位于受权限保护的位置且提示 `EACCES` / `EPERM` 时，先确认路径正确、应用已退出，再以管理员身份运行安装脚本。

## 3. 自定义安装路径

在补丁文件夹打开 PowerShell，使用 `--resources` 指定目标目录，而非 EXE 文件或上一级目录：

```powershell
node patch.mjs install --resources "D:\Antigravity\resources"
node patch.mjs status --resources "D:\Antigravity\resources"
node patch.mjs restore --resources "D:\Antigravity\resources"
```

也可以在当前终端设置环境变量，后续命令会优先使用该路径：

```powershell
$env:ANTIGRAVITY_RESOURCES = "D:\Antigravity\resources"
node patch.mjs install
```

`start_chinese.bat` 仅支持当前用户默认 EXE 路径。自定义路径安装完成后，请使用应用原有快捷方式启动。

## 4. 软件更新与词库更新

软件更新可能替换 `app.asar`，导致汉化失效。更新完成后，完全退出应用并重新运行安装脚本即可。如果新版本结构不兼容，脚本会报错，需等待补丁适配。

更新补丁时，下载并解压新版本的完整补丁包，再安装一次。安装会替换先前注入的运行时代码，不会不断追加词库。补丁不更改应用的自动更新设置，也不创建开机任务或后台服务。

## 5. 备份与还原

安装时，原版归档保存在应用的 `resources` 目录：

```text
app.asar.zh-original-<应用版本>-<摘要前12位>.backup
antigravity-zh-backup.json
```

JSON 文件保存当前版本的备份文件名、原版 SHA-256、汉化版本和安装时间。不要删除、改名或从其他版本复制这些文件。

需要撤销汉化时：完全退出应用，运行 `uninstall_chinese.bat`，然后重新启动应用。这里的“卸载”只还原应用归档，不会卸载 Antigravity，也不会删除原版备份。

还原会检查备份 SHA-256、应用版本及是否含有汉化标记。应用更新后旧版备份不能用于还原；请先重新安装补丁建立当前版本的原版备份。已有旧项目的 `app.asar.backup` 时，仅在同版本且未含汉化的情况下兼容迁移。

如果原版备份缺失或损坏，请使用对应官方安装包修复应用，再重新安装汉化。不要把旧版本的 `app.asar` 直接覆盖到新版本。

## 6. 翻译范围及限制

汉化采用完整文案匹配，处理部分大小写、空白和省略号差异，并补充计数、当前选择等动态标签。页面动态新增或更新文字后，也会继续匹配词库。部分原生菜单的固定标签在构建补丁时翻译。

运行时仅作用于应用本机顶层页面。对话正文、Markdown、编辑区、代码块、终端、文件/项目/对话/模型名称等区域设有保护；输入框仅翻译占位提示和相关界面标签，不修改已输入的值。嵌入式网页、产物 iframe 和外部网站不注入。

保护依赖应用当前界面结构。如果后续版本改变结构，可能出现漏译或误译。请在反馈中注明应用版本、补丁版本和具体位置；分享截图前隐去账号、对话和项目等个人信息。

## 7. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 提示找不到 `node` | 安装 Node.js，重新打开终端或重新运行 BAT |
| 提示找不到 Antigravity | 用 `--resources` 指向包含 `app.asar` 的目录 |
| 提示请先退出应用 | 退出主窗口和系统托盘中的后台进程后重试 |
| 显示已安装但仍是英文 | 完全退出并重启应用；检查是否安装到了另一份应用目录 |
| 只有部分英文未翻译 | 可能未进入词库，或属于正文/名称等保护区域 |
| 更新应用后汉化消失 | 退出应用，再运行安装脚本 |
| 提示旧备份版本不符 | 不要强行覆盖；先为当前版本重新安装补丁 |
| 提示结构不兼容或备份校验失败 | 保留错误信息；用对应官方安装包修复后再处理 |

## 8. 下载校验

Release 同时提供 `SHA256SUMS.txt`。下载后可执行：

```powershell
Get-FileHash -Algorithm SHA256 .\Antigravity-Chinese-Localization-v2.1.0.zip
```

将结果与同一 Release 的校验文件比较，以确认下载内容一致。

## 9. 修改词库与离线构建

`translations.txt` 每行一组 `英文|中文`。修改后需重新安装；不是只改词库就立即生效。以 `#` 开头的行作为注释，英文中的 `\n` 表示换行。存在冲突译文时脚本会报错。

以下命令仅生成文件，不安装到应用：

```powershell
node patch.mjs runtime --output runtime.js
node patch.mjs build --resources "D:\Antigravity\resources" --output app.localized.asar
```

`build` 会读取目标应用归档，输出本地汉化副本。不要发布该副本或原版备份；共享补丁源码和词库即可。更多测试方法见 [贡献说明](../CONTRIBUTING.md)。
